# Kinetic (in progress)

A minimal, colourful, fast style: one idea per beat, 1 bar each at 128 BPM, a new colour field flooding in from the last beat's focal point, a code-drawn mini UI per beat, a few words per beat.

Not built yet: only the example's data file (`film.json`, the Breakout use cases as one buyer's journey) exists. The build, look, score and render come next, once the use-case pages' copy is available (`getbreakout.ai` is blocked by this environment's network policy).
