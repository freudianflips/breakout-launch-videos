# Storyline: Plays, "Signal in. Meeting out."

**Status:** draft for the owner's confirmation. Nothing is built until it is confirmed.

**The film tells** demand gen and RevOps leaders one thing: **any signal goes in, a booked meeting comes out.** The 4 steps in between take a beat each.

| | |
|---|---|
| Look | Look test 03, the Swiss grid: off-white `#f2f1ee`, hairline grid, mono index numbers (Fragment Mono), huge Manrope 800 words, electric violet `#4c00ff` for "out." and the one element per shot that matters |
| Length | 15 s: 8 bars at 128 BPM (1 bar = 1.875 s, 1 beat = 0.47 s) |
| Rhythm | Hard cuts on the beat. Each new element snaps into its grid cell; nothing floats. The burst (2 cuts a beat) is in bars 5 and 6. |
| Sound | No narrator. A minimal, dry electronic track (a kick, a click, a sub), with a soft key-click as each mono label types on. It drops to near silence for the lockup. |
| Product | 4 real UI macros, each in a grid cell, each under a second |
