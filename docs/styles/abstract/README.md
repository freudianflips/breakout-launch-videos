# Abstract styles: motion reel

Eight wordless styles that each tell the same micro-story in 3.5 s, to pick a look for the full-suite film before any story is built (round 17 in the [style log](../../breakout-style.md)).

The story in every tile: a visitor (pink) arrives; Breakout (violet) notices it; the visitor drifts away and Breakout follows, pulsing; they meet.

| | Style | Idea |
|---|---|---|
| 01 | Light trails | Two comets on black; their trails braid as Breakout follows |
| 02 | Liquid | Metaballs; the two drops merge |
| 03 | Bauhaus | Flat primary shapes on paper; a half-disc catches a circle |
| 04 | One line | Two single pen lines drawing themselves, then knotting |
| 05 | Aurora | Soft light fields that bleed into each other |
| 06 | Dot matrix | A halftone grid; the two blooms ripple and blend |
| 07 | Gravity | Breakout as a star; the visitor's orbit decays into it |
| 08 | Swarm | 1,400 particles in two flocks that fold into one |
