# Moodboard: other styles for "Signal in. Meeting out."

12 single-frame looks, leaning into fast, animated, music-video motion. Each frame's caption says how it would move. `contact.jpg` shows them all; `m01.jpg` to `m12.jpg` are full size; `frames.html` is the source (`node docs/moodboard/shoot.mjs` re-shoots).

| # | Style | Motion |
|---|---|---|
| 01 | Strobe type | 1 syllable per 8th note; the ground flips black, violet and white on every hit |
| 02 | Glitch / datamosh | Slices tear sideways on the kick; RGB split; the real UI breaks and re-forms |
| 03 | Liquid chrome | 3D chrome type melting word to word, reflections sweeping on the beat |
| 04 | Riso pop | 2-colour misregistered print, animated at 12 fps so it boils |
| 05 | Line boil | Hand-inked outlines that wobble at 12 fps; arrows draw on; sketches snap to real UI |
| 06 | Y2K windows | Each signal pops as a retro dialog box until the screen fills; one "Meeting booked." alert wins |
| 07 | Speed tunnel | A fly-through of a violet light tunnel; signals streak past; the line lands on the drop |
| 08 | Marquee wall | 4 rows of huge type scrolling in opposite directions; speed doubles on the drop |
| 09 | Kaleidoscope UI | The real email canvas mirrored 8 ways, turning, snapping a segment per beat |
| 10 | Stop-motion collage | Paper cutouts slapping in at 12 fps, hard shadows, stickers, marker arrows |
| 11 | Signal swarm | Signal particles flock and snap into each word, then burst into the next |
| 12 | Infinite zoom | One continuous push through nested frames: signal, card, email, meeting |

03 (chrome) and 07 (tunnel) look best with real 3D or generated plates; the rest can be built in code, free.
